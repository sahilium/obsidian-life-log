# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Life Log, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please email [i@sahil.im](mailto:i@sahil.im) with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

You should receive a response within 48 hours. We will work with you to understand and address the issue before any public disclosure.

## Scope

This plugin operates entirely within Obsidian and your local vault. It:

- Stores data as plain Markdown files
- Makes no network requests
- Does not collect telemetry
- Does not access files outside your vault

## Best Practices

- Keep the plugin updated to the latest version.
- Review event files if you share your vault.
- Use Obsidian's built-in sync and git features responsibly.
